# Tank commander contract

`observeTank(state,id,memory)` reads the simulation without changing it. Each controller owns a fresh `{seen:{}}` memory per life and level. Observation includes own shield/ammo, visible contacts within 65 world units and a 234-degree forward arc, FOV/LOS-visible geometry or four-unit tactile proximity and own timestamped previous sightings. Obstacles occlude contacts. Enemy shield/ammo, RNG, hidden flag locations, projectiles outside perception and remote teammates' observations are excluded. Occluded and rear geometry beyond four units is excluded. Visible objects provide their geometric extents; this is not a complete arena map. Commander does not have a rear radar.

`buildCandidates(observation)` returns locally computed plans. Wire requests send only IDs and descriptions; retain plans in the browser and resolve choice IDs locally. At most 16 candidates include relative travel bearing/distance and destination target range in the descriptions sent to the model. Plans offer locally checked direct flag/supply navigation, engagement at 12-unit separation, left/right flanks, retreat, unexplored local sectors and a survey rotation when boxed in. Last-seen tanks are not pursuit candidates. Remembered objectives are forgotten when their visible location is empty. Exploration prefers locations outside own visited trail; it never receives hidden goals.

`commandForPlan(state,id,plan,diagnostics?)` runs every simulation tick. Uses the real movement parameters to simulate 0.65 seconds of candidate command followed by its full inertial coast to rest, checking expanded barriers/pylons/arena and all tank collision corridors. It brakes/reverses before unsafe movement and turns to recover if reverse is also blocked. Collision reflex receives local physical scene, but cannot select a hidden target or steer toward it. Cannon target must be visible and aligned now; the actual heading ray must hit that target, and any ally intersecting that ray before the target/barrier suppresses fire. No grenades are emitted. Optional diagnostic counters distinguish interventions from actual collision events. Expired plans rotate without fire. Caller must request fresh decisions at 5Hz, retain plans on asynchronous responses, and reset memory on lifecycle transitions.

Limits: local direct-path candidate generation is not global pathfinding. Dense mazes and physically trapped tanks may need a more advanced navigation layer. Dynamic-tank prediction treats other positions as stationary and includes clearance; this is not a guarantee against an adversary actively ramming a stationary tank. Commander quality must be measured separately from physical safety.

Run `node scripts/test-jev-controller.mjs`. Tests cover perception range/FOV/occlusion, observed memory, sim immutability, inertial wall prevention, windmill and target collision prevention, ally ray veto and clear-ray fire, and exploration without global goals. Disabling FOV, occlusion, or the collision veto was verified to make these regressions fail before restoring the protections. `npm run build` additionally verifies strict TS and existing sim purity. No provider calls are needed.

Clearance-overlap recovery: the tactile executor overrides plans inside 6.5 units to separate nearby hulls. Existing safety-margin overlap (physical diameter 3.2, expanded clearance 4.0) permits stationary/increasing-distance segments while still rejecting any physical-circle intersection. It selects the shorter forward/reverse turn toward an away vector; this prevents mutual zero-speed deadlocks without granting a hidden tactical objective. Exact player(45,-29)/enemy(42,-31) regression simulates both commanders for600ticks, asserting no physical overlap and final separation at least6 units.

Moving hull prediction uses relative swept segments from each neighbor's observed heading/speed, instead of freezing neighbor positions. A two-second closest-approach reflex begins separation/braking while converging trajectories still have stopping room. Existing clearance-overlap recovery remains monotonic; an exact physical boundary touch may only move outward. High-speed head-on and crossing two-controller fixtures run180ticks without hull contact; the crossing fixture demonstrably failed before this correction. This is a short-horizon physical safety estimate, not tactical knowledge of another tank's goal or plan, and unexpected acceleration/turning still needs live verification.
