# Tank commander contract

`observeTank(state,id,memory,context?)` reads the simulation without changing it. Each controller owns a fresh `{seen:{}}` memory per life and level. Level1–2 use ten-unit approximate own navigation and personally seen flag/item coordinates, retaining flag memory. Level3 adds exact own map position and all typed uncollected objective/item positions. Level5 adds all other enemy AI positions and last accepted strategies to each controller; enemy observers receive player coordinates only from their own sight or an actual enemy squad sighting. Enemy health/ammo, RNG and hidden player position/heading remain excluded. `ObservationContext` accepts `sharedSightings?:Contact[]` and `strategies?:Record<string,Strategy>`; integration must gather shared sightings only from actual current own observations. The optional context does not authorize inventing hidden player reports.

Sightings include heading last observed, source own/shared/map, seenTick/seenSeconds, ageSeconds versus observation.nowSeconds. Reports preserve original time/heading; stale shared reports enter memory without refreshing. Private exact seen objective points prevent quantization from falsely erasing remembered flags; those exact points never serialize at low tiers. Recent own shield loss or visibly approaching projectiles supplies a three-second timestamped fear window, with no hidden shooter location.

`buildCandidates(observation)` returns locally computed plans. Wire requests send only IDs and descriptions; retain plans in the browser and resolve choice IDs locally. At most 16 candidates include relative travel bearing/distance and destination target range in the descriptions sent to the model. Plans offer locally checked direct flag/supply navigation, engagement at 12-unit separation, left/right flanks, retreat, unexplored local sectors and a survey rotation when boxed in. Last-seen tanks are not pursuit candidates. Remembered objectives are forgotten when their visible location is empty. Exploration prefers locations outside own visited trail; it never receives hidden goals.

`commandForPlan(state,id,plan,diagnostics?)` runs every simulation tick. Uses the real movement parameters to simulate 0.65 seconds of candidate command followed by its full inertial coast to rest, checking expanded barriers/pylons/arena and all tank collision corridors. It brakes/reverses before unsafe movement and turns to recover if reverse is also blocked. Collision reflex receives local physical scene, but cannot select a hidden target or steer toward it. Cannon target must be visible and aligned now; the actual heading ray must hit that target, and any ally intersecting that ray before the target/barrier suppresses fire. No grenades are emitted. Optional diagnostic counters distinguish interventions from actual collision events. Missing/expired plans coast straight or brake through the same prediction guard, then survey while nearly stationary, without fire. Caller requests fresh decisions at 2 Hz by default, retain plans on asynchronous responses, and reset memory on lifecycle transitions.

Limits: local direct-path candidate generation is not global pathfinding. Dense mazes and physically trapped tanks may need a more advanced navigation layer. Dynamic-tank prediction treats other positions as stationary and includes clearance; this is not a guarantee against an adversary actively ramming a stationary tank. Commander quality must be measured separately from physical safety.

Visible pickups include their identifiable kind and amount, retained only in the tank's own seen memory. Own capacity/shield values allow precise benefit descriptions. Full shield suppresses healing; full ammo suppresses resupply, including remembered pickups. Useful supplies describe the missing-resource benefit; player flag candidates precede neutral search. Hidden pickup metadata stays absent, and enemy collection remains unsupported.

Arena recovery accepts movement already inside the outer clearance margin only while each affected axis moves inward or stays still, always preserving physical bounds. An edge reflex overrides outside-boundary waypoints and steers inward. Braking rollouts use coasting for the final sub-tick braking speed to prevent numerical velocity reversal from inventing an outward escape rejection. Passive flag guard is offered only without a currently visible opposing tank. A visible threat instead receives hold-current-vantage/aim/fire alongside engagement, flanks and retreat; normal LOS and ally-fire checks still apply. A peaceful guard retains a locally computed lookAt point toward its own known flag, so arrival faces the flag approach rather than deriving an arbitrary north heading from a zero waypoint vector. No hidden target is added.

Tactical V2 strategies are pursue, patrol, protect, explore, retreat and regroup. Peaceful enemies prefer a stable clockwise circular next segment around their nearest known flags; counterclockwise is offered only when the clockwise path is blocked. Recent damage/projectile threat or very low shields prioritizes feasible retreat/regroup/healing and withholds offensive pursuit/hold choices. Retreat/regroup may fire only at a currently reported visible target, with the existing executor requiring actual local LOS and a safe cannon ray.
